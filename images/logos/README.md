# Logos for the Education & Experience section

Drop square-ish logo images here with these exact names (PNG, ~200×200 px,
transparent or white background). Until a file exists, a coloured monogram
is shown instead, so nothing looks broken.

| File          | Used for                                             |
|---------------|------------------------------------------------------|
| `gatech.png`  | Georgia Institute of Technology                      |
| `isi.png`     | Indian Statistical Institute                         |

To use an SVG instead, change the matching `src="images/logos/…"` in `index.html`.

- `isye-lockup-white-gold.svg`: the white lockup with the GT mark in Tech Gold (#B3A369), made from the full-colour file; shown on hover in dark mode.
